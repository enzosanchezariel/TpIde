# Sistema de Gestión y Pedidos para Bar
El sistema propuesto es una plataforma de gestión y toma de pedidos para un bar o restaurante. Su objetivo principal es digitalizar la carta de comidas y agilizar el flujo de atención.

[Documentación](https://docs.google.com/document/d/1IS6LvaBQ3uGaYNkwjV88Y9n9J958zJlR-4jqzNTXqzQ)

# Tecnologías
- .NET 8
- Microsoft SQL Express 2022

# Cómo ejecutar
## Instale el SDK de .NET
https://dotnet.microsoft.com/en-us/download/dotnet/8.0
## Clone el repositorio
```
git clone https://github.com/enzosanchezariel/TpIde.git
```
## Compile el proyecto
```
dotnet build
```
## Ejecute el proyecto
```
dotnet run --project=WebAPI
```
